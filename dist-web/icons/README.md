# Icons cho Chrome Web Store

Thư mục này chứa icon của extension. Hiện tại là placeholder 1×1 px.

**Khuyến nghị:** Thay bằng icon thật trước khi đăng lên Chrome Web Store:

- **16.png** – 16×16 px (toolbar)
- **48.png** – 48×48 px (trang quản lý extension)
- **128.png** – 128×128 px (bắt buộc cho Chrome Web Store)

Có thể dùng một ảnh 128×128 rồi resize cho 16 và 48, hoặc dùng [favicon.io](https://favicon.io/) / [realfavicongenerator.net](https://realfavicongenerator.net/).
